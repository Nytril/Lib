This repository contains the Nytril core libraries, basic facts, templates, tutorial, help and examples.

Nytril is a document programming language that combines the best of both worlds. It is a c# style object oriented programming language
with objects, inheritance and polymorphism and a powerful runtime library. It is also a full typesetting language that supports the creation 
of any number of documents with sections, tables, charts and mathematical typesetting on par with Typst and LaTeX. 
Nytril runs identically on Windows and Mac.

Nytril has:
- A complete, no-compromise programming experience with classes, members, virtual functions and namespaces
- Inline code -- right in the middle of formatting -- with no "escape codes", "#" or "/" marks
- A large number of built-in formatters for a wide variety of document layout needs
- A fast and responsive Integrated Development Environment for editing and document preview
- Integrated slide-show viewer for doing presentations
- Integrated Debugger with Stack and Watch windows
- LaTeX quality math typesetting
- Native support for measurement units and conversions
- Citations and Bibliography data management
- Sub-second background compiles and syntax error underlining
- Instant document refresh
- Integrated error management that takes you right to the problem in source code
- Exports to PDF, DOCX, SVG, PNG, JPG, HTML, TXT, TEX and more
